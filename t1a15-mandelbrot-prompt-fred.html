How the Mandelbrot set is generated

For each pixel, use the complex coordinate as C and repeatedly calculate:

Zn+1 = Zn2 + C

Start with Z = 0. Points that remain bounded are in the set and appear dark. Other points receive a color based on how quickly they escape.
