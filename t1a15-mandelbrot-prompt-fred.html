How the Mandelbrot is generated

The fractal uses the formula:

Zn+1 = Zn2 + C

Start with Z = 0. For each pixel, C is its complex coordinate. Keep applying the formula. If Z stays small, the point is in the set (black). Otherwise color it by how fast it escapes. This creates the smooth colorful bands.
